# Expanded deterministic economy price sensitivity

Read-only analysis performed on 2026-10-12: 115 instantiated product-quality combinations, 3 material multipliers (0.75/1/1.25), 3 production-economy multipliers (0.85/1/1.20), and 3 modeled catalog price multipliers (0.85/1/1.15) generated 3,105 combinations. 1,232 had modeled unit cost above modeled catalog price; 1,873 did not.

This calculation traverses existing recipe inputs and labor/operating parameters; it does **not** run production or sales server functions, post transactions, or establish net-profitability. Products without actual Q5 instances are not represented. Selling channel economics, purchase lot prices and bonuses are not proven by this scenario table. Existing balances and historical transactions remain unchanged. No universal price adjustment is justified by reference-only risk counts.
